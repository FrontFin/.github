# Security Policy

## Reporting a vulnerability

Please do not open a public issue or pull request for a security problem.

Use this repository's "Report a vulnerability" button (Security tab → Report a vulnerability) to file a private GitHub Security Advisory. Include:

- what the issue is and which package/version is affected
- steps to reproduce, or a proof of concept
- the impact you believe it has

We will acknowledge receipt and keep you updated on remediation.

If you don't receive an acknowledgement, or the repository doesn't have advisories enabled, email security@meshpay.com instead.
